# Happy Birthday — Simplified Chinese

Install this folder alongside the English Content Patcher pack and Happy Birthday 3.21.0 or later. The English pack supplies the shared event and gift definitions. This dependent pack overrides only text, and only while the game language is Simplified Chinese (`zh`). Existing spouse conditions are retained.

Includes Chinese birthday greetings, spouse dialogue, event text, mail and UI strings. Translation drafts were AI-assisted and reviewed. Content Patcher tokens, mail attachments and dialogue control markers are preserved. This development-branch content pack has been statically validated, but has not been tested in game.
